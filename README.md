# Nice2Meechu

Hyperlocal, video-first social app — **https://nice2meechu.com**

- Website: React (`frontend/`), hosted on Netlify (`netlify.toml`)
- API: FastAPI (`backend/`), hosted on Render (`render.yaml`)
- Database: MongoDB Atlas · Videos: Google Cloud Storage · AI checks: OpenAI

The live branch is **`netlify-migration`**; every push to it redeploys both the website and the API.

**Start with [`handoff.md`](handoff.md)** — the full engineering and operations guide (hosting map, deploy flow, architecture, configuration, runbooks, and the rules that must not be broken).
